📋 Prompt พร้อมใช้ — เรียงตาม Level

ถามทีละอันในช่อง chat เดิว ต่อกันเลย — ไม่ต้องวางรีวิวซ้ำใน Prompt 2 และ 3

🟢 ขั้นที่ 1 — วางรีวิว + สรุปภาพรวม (เริ่มต้น)

วาง Prompt นี้ + รีวิวทั้งหมดใน ChatGPT / Gemini
ช่วยวิเคราะห์รีวิวลูกค้าเหล่านี้ให้หน่อยนะครับ: [วางรีวิว 15 ข้อตรงนี้] ขอให้สรุป: 1. ลูกค้าชื่นชมอะไรมากที่สุด? 2. มีข้อร้องเรียนหรือปัญหาอะไรบ้าง? 3. ควรปรับปรุงอะไรเป็นอันดับแรก? 4. สรุปเป็นตาราง rating 1-5 ดาว แต่ละด้าน (สินค้า บริการ ราคา การจัดส่ง)

✅ ผลที่คาดว่าจะได้

สรุปจุดแข็งและปัญหาหลัก พร้อมตารางคะแนนแต่ละมิติ — ใช้เวลาไม่ถึงนาที

🟡 ขั้นที่ 2 — Follow-up ขอ Action Plan (พิมพ์ต่อในช่องเดิม)

ไม่ต้องวางรีวิวซ้ำ — พิมพ์ต่อในช่อง chat เดิมได้เลย
จากการวิเคราะห์ข้างต้น ช่วยทำ Action Plan ให้หน่อยครับ ขอเป็น 3 อย่างที่ทำได้ทันที (ภายใน 1 สัปดาห์) และ 3 อย่างที่ต้องวางแผนระยะยาว (1-3 เดือน) แต่ละข้อระบุด้วยว่า ใช้เงินเท่าไหร่ และ AI ช่วยได้ไหม

✅ ผลที่คาดว่าจะได้

ได้แผนแบ่งระยะชัดเจน พร้อมประมาณการค่าใช้จ่าย และ AI ชี้ว่างานไหนทำเองได้ฟรีผ่าน AI

🔵 ขั้นที่ 3 — ขอ Template ตอบ Comment (พิมพ์ต่อในช่องเดิม)

โชว์ว่า AI ไม่ได้แค่วิเคราะห์ แต่ทำงานต่อได้เลย
ช่วยเขียน template การตอบ comment สำหรับ 3 กรณีนี้ครับ: 1. ลูกค้าชมสินค้า → ตอบขอบคุณแบบอบอุ่น ไม่ทางการเกินไป 2. ลูกค้าร้องเรียนเรื่องการจัดส่งช้า → ตอบขอโทษและแจ้งขั้นตอนแก้ไข 3. ลูกค้าถามเรื่องราคาแพงเกินไป → ตอบอธิบายคุณค่าโดยไม่ทำให้รู้สึกแย่ โทนภาษาควรเป็นธุรกิจ SME ไทย อบอุ่น จริงใจ ไม่ formal เกินไป

✅ ผลที่คาดว่าจะได้

ได้ template 3 แบบนำไปใช้ตอบได้เลย — key message: "AI ไม่ได้แค่บอกว่าต้องทำอะไร แต่ทำให้ด้วยเลยครับ"

หน้าเว็บง่ายๆ กรอกตัวเลขได้ คำนวณได้ — โชว์ว่า prompt สั้นๆ ก็ได้ผลแล้ว

📋 Prompt
ช่วยสร้างเว็บ HTML ไฟล์เดียวสำหรับคำนวณจุดคุ้มทุนของร้านค้าเล็กๆ ใช้ภาษาไทย กรอกราคาขาย ต้นทุนคงที่ และต้นทุนผันแปรได้หลายรายการ แล้วคำนวณจำนวนหน่วยที่ต้องขายและยอดขาย ณ จุดคุ้มทุน ออกแบบให้สวย อ่านง่าย และเปิดใช้ใน Browser ได้ทันที
✅ ผลที่คาดว่าได้

หน้าเว็บสวยขึ้น เพิ่มรายการได้ มีทั้งหน่วยและยอดขาย — "บอกละเอียดขึ้น ได้ผลดีขึ้นจริง"

📋 Prompt
ช่วยสร้างโปรแกรมคำนวณจุดคุ้มทุนสำหรับผู้ประกอบการรายย่อย เป็นไฟล์ HTML ไฟล์เดียว เปิดใช้งานใน Browser ได้ทันที โดยไม่ต้องต่ออินเทอร์เน็ต คุณสมบัติที่ต้องการ: 1. ให้ผู้ใช้กรอกราคาขายต่อหน่วย 2. ให้เพิ่มรายการต้นทุนคงที่ได้หลายรายการ เช่น ค่าเช่า ค่าแรงประจำ ค่าอุปกรณ์ ค่าไฟขั้นต่ำ 3. ให้เพิ่มรายการต้นทุนผันแปรต่อหน่วยได้หลายรายการ เช่น วัตถุดิบ บรรจุภัณฑ์ ค่าขนส่ง ค่าคอมมิชชัน 4. มีช่องเลือกประเภทต้นทุนจาก dropdown 5. มีช่องใส่รายละเอียด จำนวน หน่วย และต้นทุนต่อหน่วย 6. คำนวณต้นทุนคงที่รวม 7. คำนวณต้นทุนผันแปรต่อหน่วยรวม 8. คำนวณ Contribution Margin ต่อหน่วย 9. คำนวณจำนวนหน่วยที่ต้องขาย ณ จุดคุ้มทุน 10. คำนวณยอดขาย ณ จุดคุ้มทุน 11. แสดงผลลัพธ์เป็นตัวเลขขนาดใหญ่ อ่านง่าย 12. มีคำอธิบายสูตรแบบภาษาง่ายๆ ใต้ผลลัพธ์ 13. ออกแบบหน้าตาให้สวยงาม เรียบง่าย ใช้ภาษาไทยทั้งหมด 14. ใช้ HTML, CSS และ JavaScript ในไฟล์เดียว 15. ไม่ใช้ library ภายนอก สูตรที่ใช้: จุดคุ้มทุนเป็นหน่วย = ต้นทุนคงที่รวม ÷ (ราคาขายต่อหน่วย - ต้นทุนผันแปรต่อหน่วย) ยอดขาย ณ จุดคุ้มทุน = จุดคุ้มทุนเป็นหน่วย × ราคาขายต่อหน่วย กรณีราคาขายต่อหน่วยน้อยกว่าหรือเท่ากับต้นทุนผันแปรต่อหน่วย ให้แจ้งเตือนว่า "ราคาขายยังไม่ครอบคลุมต้นทุนผันแปร จึงยังไม่สามารถคำนวณจุดคุ้มทุนได้" ขอให้เขียนโค้ดทั้งหมดให้สมบูรณ์ พร้อมใช้งานทันที
✅ ผลที่คาดว่าได้

📋 Prompt พร้อมใช้ — ถามทีละอันต่อกันในช่อง chat เดิม

Prompt 1 ใช้คู่กับข้อมูลทั้งหมด — Prompt 2 และ 3 พิมพ์ต่อเลย ไม่ต้องวางข้อมูลซ้ำ

🟢 ขั้นที่ 1 — วางข้อมูลทั้งตาราง + สรุปภาพรวม

วาง Prompt นี้ก่อน แล้ววางข้อมูลตารางทั้งหมดต่อท้าย (หรือแนบไฟล์ .csv/.xlsx ถ้าใช้ ChatGPT Plus)
นี่คือข้อมูลรีวิวลูกค้าจาก Social Media ร้านครัวป้าแดง ทั้งหมด 60 รายการ มี 17 คอลัมน์ [วางข้อมูลตารางทั้งหมดตรงนี้ หรือแนบไฟล์ .csv] ช่วยวิเคราะห์และสรุปให้หน่อยนะครับ: 1. คะแนนเฉลี่ย (rating) โดยรวมเป็นเท่าไหร่? 2. แต่ละ platform ให้คะแนนเฉลี่ยต่างกันไหม? 3. มีรีวิว priority สูงกี่รายการ และเกี่ยวกับเรื่องอะไรบ้าง? 4. ช่องทางสั่งซื้อ (order_channel) ไหนมีปัญหามากที่สุด? 5. สรุปเป็นตาราง: platform × คะแนนเฉลี่ย × จำนวนรีวิว

✅ ผลที่คาดว่าจะได้

ได้ตารางสรุปสถิติที่ชัดเจน — เช่น Google Review อาจให้คะแนนสูงกว่า LINE OA, และ priority สูงส่วนใหญ่มาจากช่องทาง Delivery หรือ LINE

🟡 ขั้นที่ 2 — เจาะลึกเมนูและเวลารอ (พิมพ์ต่อในช่องเดิม)

ไม่ต้องวางข้อมูลซ้ำ — AI จำตารางทั้งหมดไว้แล้ว
จากข้อมูลเดิม ช่วยวิเคราะห์เพิ่มเติมครับ: 1. เมนูไหนได้รีวิวมากที่สุด? และมีคะแนนเฉลี่ยเท่าไหร่? 2. เมนูไหนมีรีวิวเชิงลบมากที่สุด? 3. รีวิวที่ระบุ wait_time_min มีเวลารอเฉลี่ยเท่าไหร่? และกลุ่มลูกค้าไหนรอนานที่สุด? 4. มีความสัมพันธ์ระหว่างเวลารอกับ rating ไหม?

✅ ผลที่คาดว่าจะได้

AI คำนวณ average wait time, เปรียบเทียบ rating ของคนที่รอนาน vs สั้น และระบุเมนูที่มีปัญหาซ้ำ — ข้อมูลนี้หาเองด้วยตาแทบเป็นไปไม่ได้ใน 60 แถว

🔵 ขั้นที่ 3 — สร้าง Dashboard สรุปผล + Action Plan (พิมพ์ต่อ)

โชว์ว่า AI ไม่แค่วิเคราะห์ แต่สร้าง report พร้อมใช้ได้เลย
จากการวิเคราะห์ทั้งหมด ช่วยสรุปเป็น "รายงานผู้บริหาร" ให้หน่อยครับ ขอเป็นรูปแบบนี้: 🔴 ปัญหาเร่งด่วน (priority สูง) — ต้องแก้ภายใน 1 สัปดาห์ 🟡 เรื่องที่ต้องติดตาม — แก้ภายใน 1 เดือน 🟢 จุดแข็งที่ต้องรักษา และช่วยแนะนำว่า AI ช่วยแก้ปัญหาข้อไหนได้บ้าง เช่น เขียน template ตอบ comment ลูกค้า หรือสร้างระบบติดตามคิว
